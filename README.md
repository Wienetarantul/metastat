# MetaStat

Помощник по Dota 2 в Telegram. Сейчас это первый шаг: бот, который привязывает профиль игрока и показывает его статистику из OpenDota.

## Первый запуск (Windows)

1. Откройте папку `MetaStat` в Проводнике.
2. В адресной строке Проводника напишите `cmd` и нажмите Enter — откроется командная строка сразу в этой папке.
3. Установите зависимости (один раз):

   ```
   npm install
   ```

4. Проверьте, что данные приходят (вместо числа — ваш Friend ID из Dota 2):

   ```
   npm run check -- 123456789
   ```

5. Запустите бота:

   ```
   npm run bot
   ```

   Пока окно открыто, бот работает. Остановить — `Ctrl+C`.

6. Откройте своего бота в Telegram и напишите `/start`.

> Если `npm` не запускается в PowerShell с ошибкой про «выполнение сценариев отключено», используйте `cmd`, как в шаге 2.

## Команды бота

| Команда | Что делает |
| --- | --- |
| `/start` | Приветствие и список команд |
| `/link 123456789` | Привязать свой профиль |
| `/me` | Моя статистика |
| `/player 123456789` | Статистика любого игрока |

Вместо числа можно прислать ссылку на профиль OpenDota, Dotabuff, STRATZ или Steam вида `steamcommunity.com/profiles/…`.

## Где взять Friend ID

В Dota 2: профиль → число под ником (Friend ID). В настройках игры должен быть включён общий доступ к данным матчей, иначе статистика будет пустой.

## Секреты

Токен бота лежит в файле `.env`. Никому его не отправляйте и не загружайте на GitHub — файл уже добавлен в `.gitignore`.

## Структура

```
bot/index.js            бот Telegram
src/opendota.js         запросы к OpenDota
src/report.js           текст отчёта по игроку
src/steamId.js          разбор ссылок и ID
src/store.js            привязки пользователей (data/users.json)
scripts/check-player.js проверка данных без бота
```
